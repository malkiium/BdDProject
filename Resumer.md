
Le projet du groupe 12 est une base de données sur les champions du monde des pilotes de Formule 1 depuis 1950.

L'objectif est de représenter les différentes saisons du championnat, les pilotes ayant remporté le titre ainsi que les écuries pour lesquelles ils couraient.

Pour cela, nous avons retenu 4 entités principales : les pilotes, les écuries, les saisons et les pays. Ces entités sont reliées par des associations permettant de représenter les relations entre les pilotes, leurs écuries, les saisons du championnat ainsi que la nationalité des pilotes et le pays dans lequel les écuries sont basées.
